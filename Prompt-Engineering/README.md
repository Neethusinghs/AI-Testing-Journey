# Prompt Engineering

A collection of reusable prompt templates and hands-on AI projects built while learning prompt engineering for QA and test automation.

## Contents

### [Templates](./Templates)
Reusable, copy-paste prompt templates.

| Folder | Purpose |
|---|---|
| [API-Testing-Templates](./Templates/API-Testing-Templates) | REST/API test suite, validation, auth, contract, performance, error handling |
| [Bug-Report-Templates](./Templates/Bug-Report-Templates) | Bug reporting, classification, analysis, notes-to-report conversion |
| [Testcase-Templates](./Templates/Testcase-Templates) | RICE-POT, test-case generator, SRD-to-cases, API cases, negative cases, regression suite |

### [Projects](./Projects)
End-to-end projects that apply the templates.

| Project | Description |
|---|---|
| [salesforce-login-page-automation](./Projects/salesforce-login-page-automation) | Selenium 4 + Java 17 + Maven + TestNG UI automation framework for the Salesforce login page |
| [project_2 Local testcase generator](./Projects/project_2%20Local%20testcase%20generator) | Two-screen Streamlit app that turns a Jira issue key into a test-case draft using a local Ollama LLM with a Groq fallback |
